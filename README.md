# 🛍️ Classic Online Shop

A **simple and professional full-stack e-commerce web application** built using **React.js, Vite, Tailwind CSS, Node.js, Express.js, and JavaScript**.

The project provides a realistic online shopping experience with features such as **user login, product browsing, product details, shopping cart management, quantity updates, product removal, and responsive design**

---

## 📌 Overview

**Classic Online Shop** is a full-stack e-commerce website developed to demonstrate the core features and workflow of a modern online shopping platform.

The frontend is built using **React.js with Vite** and styled using **Tailwind CSS**. The backend is developed using **Node.js and Express.js** to handle server-side functionality and API communication.

The application includes a **login page, product section, product details, and shopping cart**, providing a simple but realistic e-commerce experience.

The project uses a small set of **sample products** to demonstrate how users can browse products, view their details, add them to the cart, and manage their selected items.

# ⚛️ Frontend

The frontend is developed using:

* **React.js**
* **Vite**
* **JavaScript**
* **JSX**
* **Tailwind CSS**

React components are used to create reusable sections of the application such as the navigation bar, product cards, product details, login page, and shopping cart.

Vite is used as the frontend development and build tool.

---

# 🟢 Backend

The backend is developed using:

* **Node.js**
* **Express.js**

Express.js is used to create the backend server and handle communication between the frontend and backend.

The React frontend communicates with the Express.js backend through API requests.

```text
React.js + Vite
       │
       │ API Requests
       ▼
Node.js + Express.js
       │
       ▼
Backend Logic
```
